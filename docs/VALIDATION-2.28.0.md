# 2.28 validation

Automated PostgreSQL/PGlite checks cover organization scope, stale profile/team edits, lifecycle-field rejection, last-admin protection, recipient-only invitation acceptance and replay rejection, role escalation, operating area edits, private document bytes, cross-account storage access, independent reviews and anonymous/direct-write denial.

Type generation, TypeScript, the complete existing regression suite and production build are release gates. Actual Supabase Storage HTTP uploads and authenticated browser workflows require deployment smoke testing; PGlite models storage metadata and policies.
