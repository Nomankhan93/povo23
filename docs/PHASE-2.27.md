# FieldLance 2.27 — Project Workspace & Recruitment UX Consolidation

2.27 gives every authorized project one project-scoped workspace. Overview, Team, Recruitment, Field Work, Responses, Finance, Governance, Documents, and Activity are presented as tabs while existing RLS, RPC authorization, finance, payable, and audit services remain authoritative.

Recruitment now has one project context for opportunities, applications, shortlist review, offers, direct invitations, and assignments. Direct Invitations is no longer a standalone organization navigation destination.

This is a frontend information-architecture release. It introduces no database migration and does not create a second recruitment, payment, or ledger system.
