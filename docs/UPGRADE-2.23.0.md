# Upgrade to FieldLance 2.23.0

1. Apply the patch only to the audited 2.22.0 baseline.
2. Run `npm run types:generate` and `npm run metadata:generate` if not already generated by the patch.
3. Start local Supabase and apply the forward migration `20261009000700_tasks_sla_escalation_center.sql`.
4. Run `npm run test:task-center`, `npm run preflight`, `npm run test:local`, and `npm run test:operations`.
5. Browser-check Task Center in Field Worker, Organization, Project and FieldLance Staff scopes.
6. Only after local validation passes, run `npx supabase db push`.
