# FieldLance 2.28.0 — Organization Settings, Team & Compliance

Organization admins can edit scoped identity/contact details, operating areas and programs. Lifecycle status and independent verification remain staff-controlled. Optimistic versions reject stale edits. Existing verification fingerprints detect identity changes.

Team supports invitations to registered accounts, recipient acceptance/decline, cancellation, role changes and suspension/restoration. Creating an invitation does not send external email. The recipient accepts it inside their account. Project staffing remains separate. Team edits lock the organization and protect the last active admin; account and membership history are retained. Legacy platform membership administration retains its existing recovery permissions.

Private PDF/PNG/JPG compliance uploads (5 MiB maximum) use reserved paths, byte verification and immutable storage objects. Staff can independently accept/reject evidence with reasons. Expiry is visible and does not automatically suspend an organization. The existing verification workflow remains separate. These are new organization compliance records; historical onboarding evidence stays in its original application workflow.

The compliance surface retains incomplete upload reservations; retry with a new upload after resolving a failed transfer. Existing documents are retained for history. Automated reminders and document replacement/deletion are not included.
